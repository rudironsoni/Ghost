DEPLOYMENT WORKFLOW
================================================================================

Pre-Deployment:
1. Install prerequisites (Terraform, AWS CLI, kubectl)
2. Configure AWS credentials
3. Create ACM certificate
4. Generate secrets
5. Configure backend (Terraform Cloud or S3)
6. Review and customize terraform.tfvars

Deployment:
1. make init          # Initialize Terraform
2. make validate      # Validate configuration
3. make plan          # Create execution plan
4. make apply         # Deploy infrastructure (25-35 min)

Post-Deployment:
1. make configure-kubectl    # Configure kubectl
2. Deploy Cluster Autoscaler
3. Deploy AWS LB Controller
4. Deploy Ghost application
5. Configure DNS
6. Verify monitoring
7. Test backups
8. Run security scan

Maintenance:
- Daily: Monitor dashboards
- Weekly: Review costs and performance
- Monthly: Security patches, access review
- Quarterly: Version upgrades, DR drills
