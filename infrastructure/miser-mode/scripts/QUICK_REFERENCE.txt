║                         COMMON COMMANDS                               ║
╚═══════════════════════════════════════════════════════════════════════╝

┌─ FULL MIGRATION ─────────────────────────────────────────────────────┐
│ ./migrate.sh --source-host prod.example.com --interactive            │
│ - Complete migration in one command                                  │
│ - Interactive prompts for safety                                     │
└──────────────────────────────────────────────────────────────────────┘

┌─ DRY RUN (TEST MODE) ────────────────────────────────────────────────┐
│ ./migrate.sh --source-host prod.example.com --dry-run               │
│ - Test migration without making changes                              │
│ - Validates all prerequisites                                        │
└──────────────────────────────────────────────────────────────────────┘

┌─ STEP-BY-STEP MIGRATION ─────────────────────────────────────────────┐
│ 1. ./export-data.sh --host prod.example.com                         │
│    └─ Export all data from source                                   │
│                                                                       │
│ 2. ./import-data.sh --input-dir ./export_YYYYMMDD_HHMMSS            │
│    └─ Import data to target system                                  │
│                                                                       │
│ 3. ./validate-migration.sh --export-dir ./export_YYYYMMDD_HHMMSS    │
│    └─ Verify migration success                                      │
└──────────────────────────────────────────────────────────────────────┘

┌─ ROLLBACK ───────────────────────────────────────────────────────────┐
│ ./rollback.sh --source-host prod.example.com                        │
│ - Revert to source system                                            │
│ - Use if migration fails                                             │
└──────────────────────────────────────────────────────────────────────┘

╔═══════════════════════════════════════════════════════════════════════╗
║                         USEFUL OPTIONS                                ║
╚═══════════════════════════════════════════════════════════════════════╝

--dry-run              Test without making changes
--interactive          Prompt for confirmations (recommended)
--force                Skip confirmations (use with caution)
--skip-validation      Skip pre-checks (not recommended)
--config FILE          Use configuration file
--help                 Show detailed help
