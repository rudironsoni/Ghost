## Date Determination Method

Files were archived using the following date determination hierarchy:

1. **Frontmatter `date:` field** (checked first, if present in YAML frontmatter)
2. **Filename pattern:** YYYYMMDD or YYYY-MM-DD (e.g., plan1-20250203-*.md → 2025/02/03/)
3. **Directory context:** Initial state snapshot timestamp (2026-02-02 18:19:14)
4. **Git first commit date** (fallback for files without explicit dates)
5. **Filesystem modification time** (last resort fallback)

**Archive Structure:**
```
docs/archive/
├── YYYY/
│   └── MM/
│       └── DD/
│           └── source_identifier/
│               └── [original-structure]/
│                   └── file.md
```
