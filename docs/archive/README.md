# Ghost Documentation Archive

Chronological archive of all planning documents, decisions, and architectural records.

## Structure
- `YYYY/MM/DD/` - Files organized by canonical date
- `git/COMMITS.md` - Git history with patch summaries
- `PROVENANCE.md` - Source mapping and provenance
- `CHANGELOG_BY_DATE.md` - Day-by-day timeline
- `TRACEABILITY.md` - Document to commit links
- `OPEN_LOOPS.md` - Pending items and TODOs
- `DRIFT_REPORT.md` - Stale documentation claims
- `COMPONENTS.md` - Component directory
